# Ontime Standalone View Skill

This skill helps generate standalone Ontime custom views as single-file `index.html` uploads. It is intended for creating browser-based Ontime displays such as stage timers, backstage monitors, confidence monitors, lobby schedules, and other custom views that connect to Ontime data, typically through WebSocket updates.

## Documentation Sources

The Markdown files in `resources/` are sourced from the official Ontime documentation, with one exception: `CUSTOM_VIEW_DOCUMENTATION.md` is custom documentation for this skill.
